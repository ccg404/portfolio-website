How I work

AI does the typing. I do the thinking.

Plan it

I write down what the page or feature must do, who uses it, and what to leave out.

Prompt it

I give the AI clear, small tasks with the context it needs, instead of one giant request.

Read and test

I read the code, run it in the browser and DevTools, and fix anything that looks off.

Ship it

I commit to GitHub with a clear message, deploy the page and write a README.

I'm early in my career, and I'd rather be honest about it. The fundamentals come first, so when the AI gets something wrong, I can tell, and I know how to fix it.
